Excel Sheet
The sheet is built fresh from the records every time you press download, so it always matches the app. Every box of the registration form gets its own column, one row for one student, and no row can come twice. Sheet 1 is the record, sheet 2 is one profile per student with the photo and the document pictures inside, sheet 3 is the deleted students.
Backup and Restore
Records stay inside this app on this device. Take a backup now and then. Full backup also carries the photos and documents, so that file is heavy.
Restoring keeps what is already on the phone. Where the same GR number is in both, the newer record wins.

GR Number
Next auto GR will be
Auto GR runs on its own count. When you enter an old student with Auto GR Off, that typed number is not counted, no matter if it is bigger or smaller. Auto GR simply carries on from where the last auto number stopped. If a number is already taken, the app skips it and takes the next free one.
